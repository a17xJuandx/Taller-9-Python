# Programación de Computadores en Python
## Taller 9: Estructuras de Datos Avanzadas
#### Universidad Nacional de Colombia[cite: 5]

---

Este repositorio contiene la resolución del **Taller 9**, enfocado en la manipulación de estructuras de datos fundamentales y avanzadas en Python. El taller abarca el uso de cadenas, listas, tuplas, diccionarios, conjuntos y matrices, aplicando lógica de programación para resolver problemas específicos[cite: 5].

---

## Contenido del Taller

El desarrollo incluye soluciones para los siguientes temas[cite: 5]:

* **Cadenas de caracteres:** Manipulación de subcadenas, conversión entre mayúsculas y minúsculas (usando funciones integradas y bucles) y búsqueda de palabras según longitud[cite: 5].
* **Listas:** Procesamiento de datos de entrada con validación, eliminación de elementos por índice par y filtrado de elementos únicos[cite: 5].
* **Tuplas:** Operaciones básicas de suma de elementos y acceso indexado[cite: 5].
* **Matrices:** Construcción de matrices identidad, recorrido de elementos y algoritmos para verificar la simetría de una matriz cuadrada[cite: 5].
* **Diccionarios y Conjuntos:** Gestión de datos complejos, incluyendo conteo de valores pares, registro de información (frutas y precios), operaciones de teoría de conjuntos (unión, intersección, diferencia) y seguimiento de inscripciones de estudiantes en múltiples materias[cite: 5].
